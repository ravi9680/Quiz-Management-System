# 📚 Quiz Management System in C++

A feature-rich **Quiz Management System** built entirely in **C++**, using multiple `.cpp` source files. This project simulates a complete quiz platform for **students and administrators**, including question management, user authentication, quiz participation, score evaluation, leaderboard tracking, and a **"Question of the Day" streak** feature.

## 🛠 Features

- 🔐 **User Authentication** — Separate login functionality for administrators and students.
- 👨‍💼 **Admin Panel** — Add, update, delete, and manage quiz questions.
- 📝 **Quiz Participation** — Students can attempt available quizzes and submit their answers.
- 📊 **Score Evaluation** — Automatic evaluation and calculation of quiz scores.
- 🏆 **Leaderboard** — Tracks and displays student performance and rankings.
- 🔥 **Question of the Day** — Daily question system with streak tracking.
- 💾 **Data Persistence** — User, question, score, and leaderboard data are stored locally.
- 🧩 **Modular Architecture** — Functionality is separated across multiple `.cpp` source files for better organization and maintainability.

## 🚀 Getting Started

### 🧰 Requirements

- A **C++ compiler** such as GCC/G++
- Terminal or command line
- Standard C++ library

### 🔧 Compilation

```bash
g++ main.cpp -o quiz_app
```

### ▶️ Run the App

```bash
./quiz_app
```
